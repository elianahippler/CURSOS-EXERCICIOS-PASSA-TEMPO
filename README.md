## 🧪 Exercícios (código pra ler — sem um site único pra cada)

Essas pastas não entraram na tabela acima porque não têm *um* ponto de
entrada: são várias páginas/arquivos pequenos, feitos exercício por
exercício.

- **[`html-css/exercicios`](https://github.com/elianahippler/CURSOS-EXERCICIOS-PASSA-TEMPO/tree/main/html-css/exercicios)**
  — 26 mini-exercícios de HTML/CSS, cada um na sua pasta (`ex001` a `ex012b`
  e além), cada um com seu próprio `index.html`. Dá pra ver qualquer um ao
  vivo trocando o número no link, ex.:
  `https://elianahippler.github.io/CURSOS-EXERCICIOS-PASSA-TEMPO/html-css/exercicios/ex001/`
- **[`javascript`](https://github.com/elianahippler/CURSOS-EXERCICIOS-PASSA-TEMPO/tree/main/javascript)**
  — exercícios de JavaScript organizados por aula (`aula04` a `aula16ex`),
  cada um com seu próprio arquivo `.html` (ex.: `aula10/ex006.html`).
- **[`INTROPHP`](https://github.com/elianahippler/CURSOS-EXERCICIOS-PASSA-TEMPO/tree/main/INTROPHP)**
  e **[`lp/3cti-eliana`](https://github.com/elianahippler/CURSOS-EXERCICIOS-PASSA-TEMPO/tree/main/lp/3cti-eliana)**
  — exercícios de lógica de programação em PHP (variáveis, operadores
  lógicos, laços de repetição, arrays). **PHP não roda no GitHub Pages**
  (que só serve arquivo estático) — essas pastas são pra ler o código no
  GitHub, não pra ver funcionando ao vivo.

> **Nota sobre `kauane-introphp`:** tem a mesma lista de exercícios de
> `INTROPHP`, mas resolvida com o nome "Kauane" nos arquivos — parece ser a
> resolução de outra pessoa (colega de turma?), não sua. Deixei de fora da
> lista de exercícios acima; se não for pra ficar aqui, dá pra remover a
> pasta sem afetar o resto do repositório.

## Pastas ou branches?

Mesma lógica do repositório da Fatech: fica melhor em **pastas**. Assim
todo projeto e todo exercício ficam no ar ao mesmo tempo, cada um com seu
link fixo, com uma única configuração de Pages — branch serviria só se você
quisesse mostrar uma versão por vez.
